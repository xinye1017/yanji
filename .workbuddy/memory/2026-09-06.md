## 快捷操作：空白点击退出编辑态 + 长按拖动排序
- 空白退出：HomeScreen 根 Column 加 `.pointerInput(Unit) { detectTapGestures { editingQuickId = null } }`（子级 clickable 消费 tap，仅空白触发）
- 拖动排序（自研，无第三方库）：
  - Repository 加 `moveQuickStartPreset(id, toIndex)`（内存即时重排 + sortOrder 重编号）与 `commitQuickStartPresetOrder()`（松手落库）
  - 每个卡片 `detectDragGesturesAfterLongPress`：长按 = 进入编辑态（红叉同时出现）+ 开始拖动；中心点距最近块 < 0.62×max(宽,高) 时 move
  - 坐标系统一用 `boundsInWindow()`（itemTopLefts/itemSizes 两个 mutableStateMap）
  - 关键坑：pointerInput 与 onGloballyPositioned 必须在 graphicsLayer 外侧（链上在前），否则手势坐标/布局坐标会随拖动平移漂移；交换后 `dragOffset += oldTop - newTop` 补偿抓取点
  - 被拖块 zIndex(1f) + graphicsLayer 阴影 + alpha 0.94
- 顺手修复：用户并行加的 `FloatingJuanjuanBall`（悬浮卷卷球）调用把 HomeScreen 函数闭合括号插错位，celebratingCheckIn/presetToDelete 块被甩到函数外；已把调用移回 BoxWithConstraints 作用域内并补齐括号
- 编译 BUILD SUCCESSFUL。注意 zIndex 的 import 是 androidx.compose.ui.zIndex
